# Evolve

Use `AGENT_MEMORY` as the learning-library root and `AGENT_DOCTRINE` as the rules file
read before work. Run `/learn` first when current work has not yet been recorded.
Follow repository rules and the current runtime's file/memory-update constraints.

**IRON RULE:** when current evidence confirms wrong, faulty or outdated skill guidance,
correct its authoritative source immediately before reuse. Verify and date the correction,
preserve historical evidence and refresh affected references. If blocked, mark the guidance
DO NOT USE and report why. Do not wait for this command or the end of a session.

1. Read `INDEX.md`, `RETRO-LOG.md` and every active record under `skills/generated/`,
   `skills/validated/` and `failure-patterns/active/`. Read complete evidence, not summaries.
2. Promote a generated technique only with verified reuse in a later session than its
   creation. Move it to validated, add 0.2 confidence up to 0.95 and cite the evidence.
   Confidence alone, a same-session test or a planned use does not justify promotion.
3. Repair faulty metadata. Archive failed, superseded or obsolete techniques with a
   dated reason. Age alone is insufficient: 60 days without reuse also requires changed
   circumstances. Preserve archived records and verify affected references.
4. Merge genuine overlaps into the strongest record, retaining unique evidence and
   procedures. Archive the others with a pointer. Never manufacture a merge quota.
5. For failures with at least two strikes, or one critical observed failure, add a
   concise hard rule to the narrowest authorized doctrine/checklist actually read at
   work time. Mark the record `graduated` with that target; retain the failure history.
6. Check active paths, commands, APIs and versions against current evidence. Correct
   stale references immediately; archive only when the guarded subject is genuinely
   gone or superseded. Do not execute historical operational examples while curating.
7. Rebuild `INDEX.md` from current metadata and relative links. Verify all links, names,
   descriptions and confidence values; no blank or 0.00 technique rows.
8. Report exact promotion, demotion, archive, merge and graduation counts, quote new
   doctrine rules and list the top five techniques by confidence. State evidence limits.

Share only material intended for publication. Curation does not authorize operational
actions, unrelated product changes or changes outside the permitted library.
